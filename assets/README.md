# 데모 자산

시뮬 데모 전용이다. 실물 실행 경로와 학습에는 쓰이지 않는다.

## person.obj — 저장소에 담지 않는다

머리 카메라 앞에 세우는 가상 사람이다. **저장소에 올리지 않으므로 각자
로컬에 둔다.** 그래서 쓰고 싶은 모델을 라이선스에 구애받지 않고 고를 수
있다. 받은 모델은 아래로 맞춰 넣는다.

    uv run --extra demo python tools/prepare_person_mesh.py <받은것.obj>

위쪽 축, 크기, 사각면을 알아서 고친다. 머리카락·치아·속옷 같은 보조
형상이 섞여 있으면 `--list-groups` 로 보고 `--group` 으로 몸만 고른다.
맞추는 기준은 키 1.7 m, z 가 위, 원점은 몸의 중심이다 — 검출 계약의
`h` 가 거리로 읽히려면 실제 사람 키여야 한다.

### 확인된 것

- **기하 도형으로 쌓은 사람 모형은 안 된다.** 캡슐로 머리·몸통·팔다리를
  세워 봤는데 검출 모델이 한 번도 사람으로 보지 않았다. 임계를 0.01 까지
  내려도 person 은 후보에 들지 않고 가위, 신호등, 우산이 나왔다
- **제대로 된 인체 메시는 텍스처가 없어도 잡힌다.** 민무늬 살색 메시로
  각도 0 ~ 180 도, 거리 2.5 ~ 9 m 를 훑어 신뢰도 0.78 ~ 0.95 가 나왔다.
  옆모습(90 도)이 제일 낮다

## emotion/ — 저장소에 담지 않는다

감정 표현 모드에 넣을 발화다. 소리 wav 와 얼굴 프레임이 짝이고 정답 감정과
전사문이 붙어 있다. 원본은 AI Hub "한국인 감정인식을 위한 복합영상"
(멀티모달영상, dataSetSn=58) 이며, 감정 모델팀이 학습용으로 가공해 둔 것을
그대로 쓴다. **원본이 이용 약관 아래 있으므로 저장소에 올리지 않는다.**

    uv run --extra demo python tools/fetch_emotion_samples.py

감정 일곱마다 세 건씩, 사람이 영상·소리·종합을 다 같은 감정으로 본 발화만
고른다. 21 건에 8 MB 쯤이다. `--count` 로 늘린다.

### 확인된 것

- **얼굴은 실시간 영상이 아니다.** 발화 구간을 24 장으로 균등 샘플링한 것이라
  한 장이 0.25 초쯤을 맡는다. 30 fps 로 돌리면 6 초 발화가 0.8 초에 끝난다
- **얼굴 크롭에 어깨까지 들어 있다.** 눈을 기준으로 정렬해 돌린 것이라 모서리에
  검은 삼각형이 남는 장이 있다
- 소리는 모노 16 kHz 다. TTS 와 마이크도 같은 표본율로 맞춰 두었다
